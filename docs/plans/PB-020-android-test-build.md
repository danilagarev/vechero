# План: PB-020 — Android APK для физической приёмки

## Результат

Установочный APK актуального приложения «Вечеро» для телефона пользователя,
с контрольной суммой, сведениями о версии и кратким сценарием проверки.
Это тестовая сборка для установки вручную, с существующей debug-подписью проекта.

## Границы и зависимости

Исходник: текущий commit PB-020; Flutter 3.38.5, Dart 3.10.4, Gradle/AGP/Kotlin
из репозитория. App ID и продуктовые правила не меняются. В среде первоначально
нет JDK/Android SDK: установить локальные инструменты из официальных источников,
не включать SDK, кеши и ключи в Git. Ключ тестовой подписи не распространять.
Проверка на устройстве после передачи APK остаётся за физической приёмкой.

## Шаги

- [x] Подготовить JDK и минимальный Android SDK по требованиям проекта.
- [x] Собрать оптимизированный универсальный APK с тестовой подписью.
- [x] Проверить manifest, архитектуры, assets, подпись и SHA-256 файла.
- [x] Передать APK и инструкцию установки/проверки; обновить STATUS/DEVELOPMENT.

## Проверка

`flutter build apk --release`, Android build tools для проверки APK и подписи.
При изменении исходников выполнить относящиеся к ним тесты. Установка и игровой
цикл на реальном телефоне не считаются выполненными по одной успешной сборке.
