# PB-020 — проверка сохранения подготовки

Дата: 2026-11-08. Только вымышленные участники и технические проверки.
Физическая приёмка и реальные плейтесты не выполнены.

## Результаты

- `make check-mobile`: 7 тестов ядра, 39 мобильных тестов, форматирование и анализ.
  Новые 16 проверок относятся к формату и persistence; остальные защищают игровой
  цикл, приватность, motion и исправления ревью PB-015.
- `npm run check`: Prettier, TypeScript, 3 Node-теста.
- Release web build с локальным CanvasKit и отключённым service worker.
- В Chromium заполнены четыре тестовых имени и выбраны 9 минут; после старта
  сохранение содержит ровно schemaVersion, gameId, names, discussionMinutes,
  packId. Роли, локации, seed и deadline отсутствуют.
- После reload открыты каталог → правила → подготовка: визуально восстановлены
  все имена, выбранные 9 минут и текущий набор; активной карточки нет.
  [Снимок восстановления](restored.png). Flutter Web DOM inputValue до фокуса
  не отражает программно заполненные поля: сверены отрисованный текст и
  TextEditingController в widget-тесте, а не только значение DOM input.
- Через интерфейс удалены сохранённые данные: свой ключ отсутствует, поля пусты.
  [Снимок очистки](cleared.png). [Повторный reload](after-restart.png) подтверждает пустую подготовку.
- На 320×640 с text scale 2 проверены восстановление и очистка: количество игроков
  сбрасывается с 6 до 4, имена и время сбрасываются; переполнений нет.
- Асинхронная запись перед стартом дедуплицируется. Ошибка записи разрешает игру
  с уведомлением. Выход до завершения записи не запускает disposed-сессию.
- Записи и удаление упорядочены в одном adapter: поздняя запись не отменяет
  последующую очистку; ошибка не блокирует очередь дальнейших операций.

## Формат и платформа

[ADR 0002](../../adr/0002-local-setup-persistence.md),
[пример версии 1](../../../apps/mobile/test/fixtures/spy_setup_v1.json).
Android/iOS storage adapter подключён через официальный плагин, но native build
и работа настоящих DataStore/NSUserDefaults здесь не проверены: нет SDK/устройств.
SharedPreferencesAsync проверен через официальный in-memory platform backend;
реальный web backend проверен через интерфейс и reload. SDK не обновлялся.

## Оставшаяся приёмка

Физические Android/iOS, haptics, screen reader и profile-проверки PB-015;
хранилище на этих устройствах и минимум три разные компании по
[протоколу](../../playtests/PB-020-protocol.md). Наблюдения, время запуска и желание
повторить пока не измерены. Технические тесты не закрывают PB-020 целиком.
