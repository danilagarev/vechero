## Выполнено

- `make check-mobile`: форматирование, анализ без замечаний, 7 тестов ядра и
  23 мобильных теста. Полный цикл/повтор, обе победы, deadline после долгого фона,
  защита от двойного нажатия, подтверждение выхода, отмена и валидация подготовки.
- Новый тест ухода в inactive через 40 мс после открытия карточки: секрет отсутствует
  в тексте, Card и semantics после следующего кадра; возврат оставляет роль закрытой.
- Весь цикл на 320×640 с text scale 2; отдельный цикл с 12 длинными одинаковыми
  именами и inset клавиатуры 260 px. Отсутствие RenderFlex overflow.
- Галерея компонентов с крупным текстом и клавиатурой; disabled, ошибка и диалог.
- Загрузка → ошибка → повторная загрузка → подготовка: отдельный управляемый loader,
  без обращения к сети. Загрузка/ошибка включены в визуальные эталоны.
- iOS: отдельный widget-тест интерактивного возврата от левого края.
- Reduced motion: вход отображает child непосредственно, без SlideTransition.
  Дополнительный тест прерывает прорисовку результата через 100 мс включением
  reduced motion и проверяет немедленное конечное состояние.
  Все motion-компоненты учитывают disableAnimations и accessibleNavigation.
- Chromium 360×800 и осмотр 1280×900: каталог → правила → имена → настройки → четыре роли →
  обсуждение → выбор подозреваемого → результат → повтор с прежними именами.
  Проверено disabled до выбора. Browser-автоматизация использует Flutter semantics;
  после fill нужно дождаться обработки события фреймворком, иначе данные ещё
  не попадают в TextEditingController. Это ограничение автоматизации, не проверка
  реальной мобильной клавиатуры.
- Release web build с локальным CanvasKit (`--no-web-resources-cdn`). Web host служит
  только для локального просмотра. Подключена русская локализация Material.

## Контраст

Расчёт WCAG relative luminance по sRGB из NightColors, без прозрачности текста:

| Пара            | Контраст |
| --------------- | -------- |
| text/background | 15.22:1  |
| text/surface    | 12.58:1  |
| muted/surface   | 7.83:1   |
| ink/accent      | 11.30:1  |
| error/surface   | 8.50:1   |
| border/surface  | 3.35:1   |
| accent/raised   | 8.38:1   |

Проверенные пары текста проходят 4.5:1, рамка на surface — 3:1.
На реальном устройстве ещё проверить блики, яркость и читаемость таймера с расстояния.

## Открытая приёмка

- Физические Android/iOS: полный integration-тест, игра четырьмя людьми без интернета,
  haptics, TalkBack/VoiceOver, порядок фокуса, настоящая клавиатура, системные insets,
  фон/возврат и системный back gesture. SDK/устройства в этой среде отсутствуют.
- Profile-сборка и измерение кадров/памяти на устройстве. Headless Chromium
  не доказывает нативные 60/120 fps. Браузер сообщил GPU stall ReadPixels при захвате;
  ошибок JavaScript за ручной браузерный цикл не было.
- Поведение 12 участников на реальном широком экране и с нативным нелинейным
  увеличением шрифта. Widget-тесты размеров не заменяют эту приёмку.
- Продуктовый плейтест и метрика 30 секунд до старта относятся к PB-020;
  сохранение настроек/партии и онлайн не добавлены этой итерацией.

## Регрессии ревью

`review_regression_test.dart`: обычный и NightRoute при iOS reduced motion
сохраняют возврат свайпом; двойной тап в одни координаты с интервалом 100 мс
оставляет следующую роль закрытой для трёх локаций, включая «Туристический лагерь»
и «Космическая станция». После 500 мс роль открывается явным новым нажатием.
Имена тестовые, роли не выводятся в логи.
