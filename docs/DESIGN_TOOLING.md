# Инструменты дизайна PB-015

Обновлено: 2026-11-08. Задача — [полная проработка дизайна и движения](plans/PB-015-design-and-motion.md).
Это инструментарий для Flutter-продукта; web-превью служит для просмотра.

## Скиллы Codex

Установка выполняется из официального репозитория `openai/skills`, каталог
`skills/.curated`, через штатный skill-installer. Пользовательские скиллы находятся
в `~/.codex/skills`; они не становятся зависимостями мобильного приложения.

Набор для этапа:

| Скилл                                            | Назначение                                                 |
| ------------------------------------------------ | ---------------------------------------------------------- |
| `figma`, `figma-use`                             | Работа с доступным Figma-контекстом и инструментами        |
| `figma-create-new-file`, `figma-generate-design` | Новые файлы и варианты экранов                             |
| `figma-generate-library`                         | Библиотека повторно используемых компонентов               |
| `figma-create-design-system-rules`               | Правила применения дизайн-системы                          |
| `figma-implement-design`                         | Перенос выбранного дизайна в код с визуальной сверкой      |
| `playwright`, `playwright-interactive`           | Осмотр браузерного превью и сценарии взаимодействия        |
| `screenshot`                                     | Захват реального интерфейса для визуального анализа        |
| `imagegen` (уже доступен)                        | Авторская растровая графика, иллюстрации и варианты assets |

Все десять новых скиллов из таблицы установлены 2026-11-08; `imagegen` был доступен
до этой установки. Новые скиллы доступны со следующего сообщения. Перед использованием читать соответствующий
SKILL.md. Установленный скилл не означает, что его MCP, runtime или аккаунт подключён.
В частности, Playwright browser/runtime нужно проверить отдельно; web-семантика
Flutter может требовать адаптации сценария и визуальной проверки.

## MCP и внешние приложения

Каталог интеграций проверен; предложены три взаимодополняющих сервиса:

| Интеграция     | Для чего                                                  | Подтверждённое состояние                       |
| -------------- | --------------------------------------------------------- | ---------------------------------------------- |
| Figma          | Редактируемые макеты, компоненты, сравнение с реализацией | Найдена, установка/подключение не подтверждены |
| Product Design | Поиск направлений, аудит flow, интерактивные прототипы    | Найдена, установка/подключение не подтверждены |
| MagicPath      | Сравнение направлений и совместный canvas для прототипов  | Найдена, установка/подключение не подтверждены |

Установка/авторизация внешнего приложения требует действия владельца аккаунта.
Проверять доступные инструменты после подключения; не считать предложения
подключёнными MCP. Не добавлять фиктивные серверы, токены или чужие credentials
в конфигурацию проекта. Публично публиковать макеты и загружать материалы во
внешние сервисы только в рамках отдельного разрешения пользователя.

Без этих подключений работа продолжается: локальные композиции, генерация assets,
Flutter-компоненты, анимации, скриншоты и проверяемое браузерное превью. Выбирать
инструмент под конкретный результат, а не делать каждый экран в трёх редакторах.

## Локальные средства и assets

- Flutter theme/ThemeExtension, штатные animation API и CustomPainter — основной
  способ реализации. Widget/integration/golden-тесты — защита сценария и визуала.
- Штатный Dart/Flutter MCP — кандидат для анализа проекта и runtime-инспекции:
  при подготовке проверить поддержку закреплённым SDK и доступные инструменты.
  В текущей сессии подключение такого сервера не настроено и не подтверждено.
- Flutter DevTools и profile-режим на устройстве — диагностика кадров и нагрузки;
  браузерный осмотр не заменяет проверку Android/iOS, haptics и screen reader.
- Chrome/DevTools, CDP или Playwright — скриншоты, размеры viewport, проверка
  переходов и запись превью. Chrome/CDP уже использовались для просмотра PB-010.
- Генерация изображений доступна встроенным инструментом; отдельный сервис для
  этого не нужен. Текст и интерактивные элементы реализуются во Flutter, графика
  не должна превращать экран в одну некликабельную картинку.
- Иконки/простые векторные элементы — единая система SVG или кодовая отрисовка;
  шрифты с кириллицей и нужными начертаниями — локальные assets с лицензией.
- Rive/Lottie, дополнительные библиотеки, звуковые assets и шрифтовые пакеты
  добавляются только при фактическом использовании, с версиями и лицензиями.
  Установка всех доступных npm/Dart-пакетов не является результатом дизайна.

## Рабочий процесс

Аудит → 2–3 визуальных направления → выбор → токены/компоненты → все экраны →
motion/haptics → скриншоты и записи → исправления → проверки на устройстве.
Хранить объяснение выбора, исходники и экспортируемые материалы в `docs/design/`,
а правила системы — в `docs/DESIGN_SYSTEM.md` при реализации PB-015.

Для повторной установки скиллов использовать системный `skill-installer` и
перечисленные имена из `openai/skills`. Не фиксировать локальные пути SDK, токены
или конфигурацию аккаунта в переносимых настройках проекта.
