# Продукт и происхождение требований

Дата разбора: 2026-11-07. Источник — [публичная беседа](https://chatgpt.com/share/6aef6de1-0910-83ed-bbef-71fa9ff0bc03).

## Подтверждено пользователем

- Мобильное приложение для Android и iPhone.
- Компания от четырёх человек; несколько игр и разные темы, в том числе игра про шпиона.
- Оба способа взаимодействия: один телефон и отдельные телефоны участников.
- Премиальный стиль.
- Цель — публикация в магазинах приложений.
- Оформить технический фундамент и репозиторий для работы ИИ-агентов.
- 2026-11-08 для PB-015 выбран вариант 01 — «Полночный клуб»: тёмные поверхности,
  зелёный акцент, знак взгляда, крупная типографика и мягкие формы.
  [Сравнение направлений](design/pb-015/README.md).

- Анимации прорабатываются одновременно с визуалом и взаимодействиями экранов,
  а не отдельным завершающим этапом (уточнение пользователя 2026-11-08).

## Рабочие решения этой итерации

Это выбор реализации на основе предложений из беседы, а не дополнительные цитаты
пользователя. Они обратимы и записаны в [ADR](adr/0001-foundation.md).

- С 2026-11-08 временное название — «Вечеро». Пользователь согласился оставить его
  пока, но название ему не нравится; окончательным решением его не считать.
  Рабочая формулировка для магазина — «Вечеро: игры для компании».
  Техническое имя `partybox` сохраняется; товарный знак и store identifiers ещё не выбраны.
- Flutter/Dart, NestJS/TypeScript, затем PostgreSQL и Socket.IO.
- Первый проверяемый продуктовый срез: одна локальная игра «Шпион» без регистрации
  и интернета. Онлайн остаётся обязательным направлением продукта, но не блокирует
  проверку локальной механики.
- Русский язык и 4–12 игроков для первого среза; один шпион, один раунд за партию.
- Тематические пакеты в JSON, начальный контент входит в приложение.
- Визуальное направление: тёмные спокойные поверхности, читаемая типографика,
  один заметный акцент, короткие анимации и тактильная обратная связь.
- Монетизация, аналитика и crash reporting подключаются отдельными задачами.
  Freemium из исходного ответа — гипотеза, а не утверждённая бизнес-модель.

## Первый пользовательский сценарий

Каталог → правила «Шпиона» → имена игроков → настройки → экран передачи телефона →
личная роль → скрытие роли → следующий игрок → обсуждение с таймером → выбор
подозреваемого → раскрытие → новая партия с прежними именами.

Запуск после знакомства с приложением целимся уложить в 30 секунд. Правила должны
помещаться на одном коротком экране. Это цели для плейтеста, а не уже измеренные метрики.

## До публичного релиза нужно решить

1. Финальное название, reverse-domain ID и владелец developer accounts.
2. Обязателен ли онлайн в первой store-версии; состав первых игр и языков.
3. Аудитория, возрастные темы, права на названия, тексты и иллюстрации.
4. Платные наборы, восстановление покупок, аналитика и обработка данных.

Сроки 4–7 и 9–14 недель в исходной беседе — предварительные оценки ассистента.
Новый календарный план составляется после первого плейтеста и уточнения релизного объёма.
