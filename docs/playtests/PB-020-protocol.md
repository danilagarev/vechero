# PB-020 — протокол реальных плейтестов

Статус: подготовлен 2026-11-08; реальные сессии ещё не проведены.
Нужно минимум три разные компании по 4–12 человек. Перед приёмкой завершить
открытые проверки Android/iOS из PB-015. Наблюдения записывать обезличенно:
номер сессии, размер компании, платформа, действия и затруднения. Не сохранять
роли, секретные локации, записи разговоров или имена участников в Git.

## Один прогон

1. На физическом устройстве открыть приложение без интернета. Новые участники
   самостоятельно читают правила и готовят партию, наблюдатель не подсказывает.
2. Замерить время от показа каталога до первой закрытой карточки передачи.
   Цель 30 секунд относится к повторному запуску после знакомства; первый запуск
   записать отдельно. Не включать время обсуждения в эту метрику.
3. Пройти раздачу, обсуждение, голосование и результат. Отметить число попыток
   открыть чужую карточку, двойных нажатий, вопросов «кому передать» и возвратов.
4. Открыть роль, свернуть/вернуть приложение: вернуться должна закрытая карточка.
   Уйти в фон во время обсуждения, проверить оставшееся время/переход по deadline.
5. Начать ещё раз с теми же участниками; отдельно закрыть приложение и открыть
   новую подготовку: имена, время и набор восстановлены, активная партия — нет.
   Удалить сохранённые данные и повторно открыть подготовку: имена пустые.
6. Проверить крупный шрифт, маленький экран, клавиатуру, TalkBack/VoiceOver,
   reduced motion и haptics. Для профиля кадров использовать profile build,
   не делать вывод о производительности по debug/web.
7. Спросить: «Хотите сыграть ещё раз?» и «На каком шаге было непонятно, что делать?».
   Записать ответы кратко и без персональных деталей; не подменять наблюдения оценкой автора.
