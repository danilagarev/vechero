Обновлено: 2026-11-08. Итерация PB-001.

## Реализовано

- Git `main`, npm workspaces и lockfile; Flutter/Dart packages с lockfiles.
- `AGENTS.md`, архитектура, продуктовые требования с происхождением, ADR, правила,
  проект сетевого протокола и backlog с критериями приёмки.
- Flutter-каталог «Шпион», экран правил, тёмная тема и Android/iOS host-проекты.
- Чистое Dart-ядро: 4–12 игроков, случайная роль, порядок раздачи, deadline,
  переход к голосованию, выбор подозреваемого и результат.
- Личные карточки и публичная проекция; до результата она не содержит секретов.
- Авторский стартовый набор из восьми локаций и строгая JSON-схема; тесты контента.
- NestJS `/health`, TypeScript strict и HTTP-тест реального endpoint.
- Форматирование, make-команды, CI и Dependabot, шаблоны PR и плана работы.

## Проверки

- `npm ci --ignore-scripts` — чистая установка из lockfile прошла.
- `npm run check` — Prettier, TypeScript strict и 3 Node-теста прошли.
- `make check-mobile` — форматирование, статический анализ и тесты Dart/Flutter.
  7 тестов ядра и 3 widget/asset-теста проходят, в том числе большой шрифт на 320×640.
- `dart pub get --enforce-lockfile` и `flutter pub get --enforce-lockfile` прошли.
- `npm run dev:backend` запущен с watcher; реальный `/health` вернул `{"status":"ok"}`.
- Локальные Markdown-ссылки проверены; отсутствующих файлов не найдено.

за пределами приложения заменён на Flutter-пакет `partybox_game_content`. Тест
проверяет присутствие корректного package asset key в manifest и загрузку JSON.
`make bootstrap` и `make check` повторно прошли в чистой копии staged-файлов:
все 13 тестов успешны, lockfiles не изменились, JSON находится внутри asset bundle.
