# «Полночный клуб» — визуальная система «Вечеро»

Выбрана пользователем 2026-11-08 после [сравнения трёх направлений](design/pb-015/README.md).
Реализация: `apps/mobile/lib/src/design/`. Правила игры остаются в game_core.

## Цвет и поверхности

| Роль       | Значение  | Применение                            |
| ---------- | --------- | ------------------------------------- |
| background | `#141B1C` | Фон экранов                           |
| surface    | `#202C2A` | Карточки, поля, диалоги               |
| raised     | `#2B3A35` | Выбор и недоступное действие          |
| accent     | `#B7E77C` | Основное действие, таймер, обложка    |
| ink        | `#182323` | Текст/графика на акценте              |
| text       | `#F3EFE7` | Основной текст                        |
| muted      | `#B5C2BA` | Подсказки и вторичный текст           |
| border     | `#66806D` | Рамки полей и карточек                |
| error      | `#FFB4AB` | Текст ошибки и рамка невалидного поля |

Цвета определены в NightColors и привязаны к ColorScheme. Светлая тема пока
не разрабатывается. Цвет не заменяет текст: выбор обозначают radio и подпись
«Выбор компании», результат — заголовок и объяснение, ошибка — сообщение у поля.
Фокус поля — акцентная рамка 2 px; кнопки и radio используют состояния Material
для клавиатурного фокуса, hover, disabled и pressed.

Контраст вычисляется по WCAG relative luminance. Основные пары текста должны
проходить 4.5:1: text/background, text/surface, muted/surface, ink/accent,
error/surface. Точные значения приведены в [материалах проверки](design/pb-015/verification.md).
Один расчёт не заменяет проверку реального экрана и TalkBack/VoiceOver.

## Типографика и сетка

Локальный Manrope с кириллицей, статические начертания 400, 700 и 800. Шрифты
загружаются из bundle без Google Fonts API. [Источник, лицензия и воспроизведение](../apps/mobile/assets/fonts/SOURCES.md).
Material Icons из Flutter SDK используются для системной навигации и элементов
формы (лицензия Flutter/Material Icons — Apache 2.0); внешних icon packages нет.

- Заголовок каталога: 40/1.1, 800, tracking −1.6; название игры: 48.
- Заголовки экранов/секрета: 30–34/1.14–1.16, 800.
- Основной текст: 15/1.5 и 16/1.55; подписи кнопок: 14, 700.
- Рубрики: 11/1.5, 700, tracking 1.8. Они дополняют заголовок, а не заменяют его.
- Таймер: 80/1.1, 800, tracking −4; scaleDown только для цифр на узком экране.
  Screen reader получает полную словесную длительность через Semantics.
- Контент ограничен 560 px; боковые поля 24 px. Ритм: 8, 12, 16, 24, 36.
- Радиусы: поверхности 28, кнопки/поля/выбор 18, бейджи 99. Без тяжёлых теней.
- Основная кнопка минимум 56 px, текстовая 52 px, остальные цели — штатные Material
  с минимумом 48 px. Текст кнопок переносится, высота может расти.

Все экраны прокручиваются, учитывают safe area и клавиатуру. Поля имён сохраняют
TextInputAction.next/done и textCapitalization.words, клавиатура закрывается перед
настройками. Длинные имена переносятся на игровых экранах; одинаковые различаются
номером игрока при голосовании. Содержимое диалога выхода прокручивается при
крупном тексте. Текст не обрезается ради фиксированной высоты карточки.

## Компоненты и авторская графика

NightPanel — поверхность/акцентная обложка; NightButton — основное действие;
NightEyebrow — рубрика; NightBadge — метаданные; NightRule — короткий шаг правил.
Поля и radio опираются на Material с общей темой: доступность и клавиатурное
управление остаются штатными. Галерея включает заголовки, обложку, кнопки,
disabled, поля/ошибку, закрытую карточку, прогресс и диалог.

NightArt рисует собственные векторы CustomPainter: взгляд с кругами (обложка и
шпион), печать (защита/победа команды), созвездие (мирный игрок/обсуждение).
Графика исключена из semantics: роль, локация и победитель всегда написаны текстом.
Это исходники проекта; внешние изображения и сгенерированные bitmap-assets
не используются. Для следующей игры обложка может получить другой знак внутри
той же системы поверхностей, текста и действий.

## Движение и обратная связь

По уточнению пользователя анимации прорабатываются вместе с каждым экраном и
проверяются в превью в той же итерации. Они входят в готовность взаимодействия.

| Событие                 | Реализованное поведение                                      |
| ----------------------- | ------------------------------------------------------------ |
| Переход каталог/правила | Fade + горизонтальный сдвиг 4%, 240 мс, easeOutCubic         |
| Возврат маршрута        | 180 мс; выход из активной партии сначала скрывает секрет     |
| Новый этап/участник     | Вход 180 мс, fade + вертикальный сдвиг 2.5%                  |
| Открытие роли           | Только вход нового содержимого за 180 мс                     |
| Скрытие/фон/передача    | Немедленное удаление роли; нет анимированного outgoing child |
| Нажатие кнопки          | Scale 0.985 за 120 мс, без задержки команды                  |
| Выбор подозреваемого    | Radio + акцентная рамка и явное имя                          |
| Таймер                  | Цифры по deadline, прогресс интерполируется за 180 мс        |
| Результат и повтор      | Вход этапа 180 мс; графический знак раскрывается за 420 мс   |

На iOS маршруты сохраняют штатный интерактивный переход назад MaterialPageRoute;
при reduced motion контент меняется без декоративного движения.

NightEntrance владеет только текущим child. AnimatedSwitcher, flip и overlay для
секретов отсутствуют. При смене фазы/игрока старое поддерево удаляется, animation
controller утилизируется; команды не ожидают завершения motion. Ядро/контроллер
сохраняют защиту от повторного нажатия. После передачи раскрытие следующей карточки блокируется на 500 мс, чтобы
второе физическое нажатие не показывало чужую роль. Этот UX-барьер действует
также при reduced motion и не задерживает скрытие секрета.

Скрытие карточки при фоне и отмене выхода
работает во время незавершённого входа; возврат оставляет карточку закрытой.

MediaQuery.disableAnimations и accessibleNavigation отключают fade/slide/scale
и интерполяцию прогресса. Декоративных циклов нет. Открытие остаётся отдельным
действием. На основных кнопках и radio вызывается HapticFeedback.selectionClick;
сценарий не зависит от наличия вибрации. Звук не добавляется: телефон общий,
партия строится на разговоре. Нативные haptics и плавность ещё требуют устройства.

## Галерея и превью

Из `apps/mobile`:

```sh
flutter run -d web-server --web-hostname 127.0.0.1 --web-port 8716
flutter run -d web-server --web-hostname 127.0.0.1 --web-port 8717 --dart-define=DESIGN_GALLERY=true
```

Галерея доступна только в non-release сборках с явным define. В release всегда
запускается обычный каталог. Web host добавлен для локального просмотра мобильного
интерфейса, а не как отдельный сетевой продукт. Публикация не выполняется.
Для release-превью без CDN: `flutter build web --release --no-web-resources-cdn --pwa-strategy=none`,
затем локальный HTTP-сервер с корнем `build/web`.

В [снимках и отчёте](design/pb-015/verification.md) различены Flutter golden,
браузерная проверка, выполненные сценарии и открытые пункты на Android/iOS.
PB-015 нельзя считать полностью принятой по одному браузерному превью.

### Развитие motion после первого просмотра

NightResultArt раскрывает публичный знак результата за 420 мс (easeOutCubic):
кольцо прорисовывается по дуге, лучи печати растут из центра, знак увеличивается
с 0.92 до 1. Для победы шпиона знак взгляда открывается из центра. Заголовок,
объяснение и повтор доступны сразу, эффект не задерживает команды. Текст роли
не оборачивается этой анимацией. При reduced motion сразу выводится конечный
знак; включение настройки посреди эффекта также немедленно его завершает.

Выбор подозреваемого использует анимацию цвета и формы Material за 120 мс,
при reduced motion — нулевую длительность. В галерею добавлены повтор анимации
результата и переключатель reduced motion, чтобы сравнивать оба варианта.
